# Kas · Club Treasury (demo)

Clickable demo of a club finance system for UNITEN clubs: receipts required, president approval, event budgets, monthly statements, audit log and a public transparency view.

Demo only. Data is stored in your browser (localStorage). Use the role switcher at the bottom left to try Treasurer, President and SRC Auditor views.

Production plan: Next.js + Supabase (Auth with UNITEN Google login, RLS, Storage for receipts) on Vercel.
